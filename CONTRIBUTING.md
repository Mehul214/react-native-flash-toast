# Contributing to react-native-flash-toast

Thank you for your interest in contributing! Community contributions are welcome to keep this library modern, performant, and reliable for developers worldwide.

## Development Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/Mehul214/react-native-flash-toast.git
   cd react-native-flash-toast
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run typecheck and tests:
   ```bash
   npm run typecheck
   npm test
   ```

4. Build the package:
   ```bash
   npm run build
   ```

## Pull Request Guidelines

- Ensure `npm run typecheck`, `npm test`, and `npm run build` pass without warnings.
- Keep changes clean, typed, and backwards-compatible whenever possible.
- Update documentation or example apps when adding new props or features.
- Follow conventional commits where feasible (`feat: ...`, `fix: ...`, `docs: ...`).
